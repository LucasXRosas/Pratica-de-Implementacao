# Arena Sports - Reserva de Quadra Esportiva

Aplicação mobile desenvolvida para React Native com **Expo (SDK 54)** e **TypeScript**, focada em um formulário interativo de reserva de quadras esportivas com validações dinâmicas, estados globais e gerenciamento de ciclo de vida.

---

## Pré-requisitos

Antes de começar, garante que tens instalado na tua máquina:

1. **Node.js**: Versão 18 LTS ou superior.
2. **Git**: Para clonar o repositório.
3. **Expo Go**: Aplicativo instalado no teu telemóvel (Android ou iOS) **OU** um emulador (Android Studio / Xcode Simulators) configurado.

---

## Passo a Passo de Instalação e Execução

### 1. Clonar o repositório
Abre o teu terminal e executa o comando:

```bash
git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
```
### 2. Instalar dependências
```bash
npm install
npx expo install react-native-safe-area-context expo-status-bar
```
### 3. Executar o projeto
```bash
yarn start
```
